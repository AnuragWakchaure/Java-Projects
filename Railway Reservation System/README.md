# 🚆 Railway Reservation System (Java Project)

Welcome to the **Railway Reservation System** — a simple Java-based console application that simulates basic railway ticket booking functionality. This project demonstrates core Java concepts like file handling, object-oriented programming, and menu-driven applications.

---

## 🧠 Features

- 📋 View Train Details  
- 🎫 Book Tickets  
- ❌ Cancel Reservation  
- 📂 View Booked Tickets  
- 🛡️ Validates input and prevents double bookings  
- 💾 Uses file handling to store and retrieve data persistently

---

## 💻 Tech Stack

- **Language:** Java  
- **Concepts Used:**  
  - Classes & Objects  
  - File Handling  
  - Loops & Conditionals  
  - Exception Handling  
  - Menu-Driven UI

---

## 📁 File Structure

```bash
Railway Reservation System/
│
├── railway.java      # Main source code for the reservation system
├── train.txt         # Sample file containing train details
├── reservation.txt   # Stores ticket bookings
└── cancellation.txt  # Stores cancelled ticket info
````

---

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/AnuragWakchaure/Java-Projects.git
   cd Java-Projects/Railway Reservation System
   ```

2. Compile the Java file:

   ```bash
   javac railway.java
   ```

3. Run the application:

   ```bash
   java railway
   ```
